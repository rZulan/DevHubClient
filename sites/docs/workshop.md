# Workshop tools

Select an organization and project to open its Workshop. Project tools keep diagrams, designs, and planning notes close to the work they describe.

| Tool | What to use it for |
| --- | --- |
| ERD | Model tables, columns, keys, and relationships |
| Ideation | Sketch workflows and UML diagrams |
| UI editor | Draft screens and prototypes |
| State machine | Map states and transitions |
| Notes | Keep project decisions and working notes |

If a tool opens in view-only mode, ask an organization owner to check your role permissions.
