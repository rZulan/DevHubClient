# ERD import and export

Open **Workshop → ERD** in your project. Start with **Table** or load the example diagram.

## Import a schema

1. Drag a `.sql` or `.json` file from File Explorer onto the canvas, or select **Import → Choose file**.
2. For SQL, choose the database target that matches the schema.
3. Review the filename, table and relationship counts, and any import notes.
4. Select **Replace current ERD** to load the diagram. Zevont arranges the tables and fits the imported diagram to the canvas.

An import replaces the current tables and relationships. Export a JSON draft first if you need a separate backup.

## Export a diagram

Open **Export** and choose **Export as SQL**, **Export as PNG**, or **Export draft (JSON)**. SQL contains the schema for your selected database. Use PNG to share a diagram and JSON to reimport an editable draft.
