# Discovery placeholder avatars

These 24 fictional placeholder portraits were generated with the DiceBear HTTP API
using deterministic `devhub-community-*` seeds and the `lorelei` style.

- Source: https://www.dicebear.com/styles/lorelei/
- License: CC0 1.0
- Generated size: 128 x 128 PNG

They are bundled locally so the Discovery page has no runtime dependency on the
DiceBear service.
